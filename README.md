# 🐍 Snake Game in Python

A classic Snake Game developed using Python's Turtle module. The game includes smooth snake movement, food generation, score tracking, high score tracking, border wrapping, and collision detection.

---

## 📌 Features

✅ Snake movement using Arrow Keys

✅ Random Food Generation

✅ Snake Body Growth

✅ Live Score

✅ High Score

✅ Border Wrapping

✅ Self Collision Detection

✅ Pause Game using Space Key

---

## 🛠️ Technologies Used

- Python 3
- Turtle Module
- Random Module
- Time Module

---

## 🎮 Controls

| Key | Action |
|------|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| Space | Pause |

---

## 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/Vinay1213143/Snake_Game.git
```

Go inside project

```bash
cd Snake_Game
```

Run

```bash
python snake_game.py
```
